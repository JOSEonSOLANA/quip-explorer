About Quip Explorer

This explorer queries the Quip Testnet via a public bootnode RPC endpoint.

Wallet Explorer — search SS58 addresses to view balance and full transaction history. A background scan from block 1 to the latest block runs progressively, showing results as they are found.

Block Explorer — browse recent blocks, view extrinsics and events. Click a block number to see its details, extrinsics, and events.

Chain: Quip Testnet (tQUIP, 12 decimals, SS58 prefix 42)
